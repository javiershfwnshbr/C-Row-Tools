# C-ROW [ VIP ]

Cyber Matrix CLI Toolkit & Terminal Console for **Termux (Android)** and **Windows / Linux**.

## 🚀 Fitur
- **Opening Animation**: Skull ASCII art + Typewriter "Welcome My Friend" dengan latar Matrix green binary.
- **Header C-ROW**: 3D shadow block letters dengan animasi sirkuit cahaya perimeter 180° berputar.
- **Menu Tools**: Tabel 2-kolom berkontras tinggi dan bebas flicker untuk kenyamanan membaca.
- **Responsive**: Pas di layar vertikal Termux HP (~28 baris visual) tanpa terpotong atau perlu scroll.

## 📱 Cara Install & Jalankan di Termux (HP Android)

1. Buka aplikasi **Termux** di HP Anda.
2. Jalankan perintah instalasi berikut:
```bash
pkg update && pkg install git python -y
git clone https://github.com/<USERNAME-ANDA>/c-row.git
cd c-row
python c_row.py
```

## 💻 Cara Jalankan di Windows CMD
```cmd
python c_row.py
```
